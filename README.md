Create a beautiful, sweet, interactive website dedicated to making **Dassy (Dasven)** smile and feel appreciated. This is NOT an apology website and should NOT ask her to forgive me or make any decision. The only purpose is to brighten her day and make her feel cared for.

### Overall Theme

* Main color: **soft blue / baby blue**
* Secondary colors: white, light cyan, subtle lavender
* Style: cute, romantic, peaceful, wholesome, elegant
* Modern glassmorphism design with soft gradients
* Add subtle glowing particles, floating hearts, stars, and small bubbles
* Smooth animations and transitions
* Make it look premium and professionally designed, not childish
* Fully responsive on mobile and desktop

### Opening Screen

Show a beautiful blue animated background with floating hearts and stars.

**"I made this little place just to give you a reason to smile today."**

**"Open this little surprise ✨"**

### Visual Effects

Add:

* Floating hearts
* Tiny stars
* Soft glowing particles
* Gentle bubbles
* Smooth page transitions
* Heartbeat animation on important hearts

Do not overdo the animations. Everything should feel calm, elegant, and comforting.

### Important Emotional Design Rule

The website should NEVER make Dassy feel guilty, pressured, obligated, or responsible for my feelings.

Avoid phrases such as:

* "Please forgive me."
* "Give me another chance."
* "Don't leave me."
* "I need you."
* "You have to reply."
* "Choose me."

The website should communicate only:

**"I hope you're okay. I hope you smile. I hope your day gets a little better."**

### Technical Requirements

* Use clean HTML, CSS, and JavaScript.
* Keep HTML, CSS, and JS organized into separate files.
* Make it fully responsive.
* Optimize animations for mobile devices.
* Use accessible buttons and readable typography.
* Make sure all interactions work correctly.
* Do not require a database or backend.
* The final website should work directly on GitHub Pages.
* Make the code clean and easy to edit later.

Overall feeling:

**soft blue + peaceful + cute + comforting + wholesome + elegant + "I just want to make you smile" energy.**
